## 给执行 agent 的共同约束

- 遵守仓库根目录的 `AGENTS.md`：只动 1.85C 板级目录；不改核心层；不手改 `build/`、`releases/`、`managed_components/`、`sdkconfig*`。
- 改动后只格式化被触碰的 C/C++ 文件，使用仓库 `.clang-format`。
- 不要把任何真实地址、账号、密码写进代码、文档、测试或提交。
- 烧录自用设备只写 APP 分区（保留 NVS，避免重新配网）。
- 每个工单结束时报告：测了什么、没测什么、哪些必须真机验证。构建成功不等于硬件验证。
- NVS 命名空间与键名为持久化 API，一旦确定不要再改。
