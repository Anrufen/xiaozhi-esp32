# 03 — 未配置状态：明确提示、零网络请求、无示例数据

**What to build:** 朋友拿到不含个人配置的固件时，两个服务都显示清晰的"未配置"，设备不会去请求任何网络，也不会展示我的示例数据。已配置但失败时，界面能分辨"认证失败"和"网络不可达"。

**Blocked by:** 01 — 配置模块 + Navidrome 端到端可配置；02 — Beszel 端到端可配置

**Status:** ready-for-agent

- [ ] 服务"未配置"时，不创建对应的网络任务，不发起任何请求（含定时触发的周期拉取）
- [ ] Beszel 页面在未配置时显示"未配置"提示，不再展示示例节点数据
- [ ] 音乐页面在未配置或无曲目时显示明确状态，不再使用内置的示例曲目列表；该内置列表（含个人曲库的曲目 ID）从源码中移除
- [ ] 已配置但失败时，界面区分认证失败与网络不可达；沿用现有间隔，不引入无限快速重试
- [ ] 通过 MCP 完成配置后无需重启即可从"未配置"切换到正常工作
- [ ] 三类状态（未配置、认证失败、网络不可达）都有串口日志可供排查，且日志不含密码
- [ ] 1.85C 变体构建通过；最终报告写明需真机验证：空配置开机无请求、配置后切换、错误密码提示
