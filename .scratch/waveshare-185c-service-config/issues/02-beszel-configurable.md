# 02 — Beszel 端到端可配置（地址/账号/密码/刷新与轮播间隔）

**What to build:** Beszel 的 Hub 地址、账号、密码、数据刷新间隔、轮播切换间隔都可以配置：出厂默认值来自 menuconfig，设备上以 NVS 为准，可通过新增的 MCP 工具修改并立即生效、重启保留。修改后设备会用新参数重新登录并拉取，不再沿用旧的登录 token。

**Blocked by:** 01 — 配置模块 + Navidrome 端到端可配置

**Status:** ready-for-agent

- [ ] 复用 01 的配置模块，扩展出 Beszel 的字符串项与两个整型项（刷新间隔默认 15 秒，轮播间隔默认 5 秒），键名遵循 SPEC 的 NVS 约定
- [ ] Kconfig 新增对应项，地址/账号/密码默认为空；间隔项默认保持现有行为（15 / 5）
- [ ] 间隔值非法（≤0 或超出合理上限）时回退默认值，该规则有宿主机单元测试
- [ ] 源码与头文件中不再出现写死的 Beszel 地址、账号、密码；现有刷新与轮播逻辑改为读取配置值
- [ ] 新增 Beszel MCP 设置工具，可设置地址、账号、密码、两个间隔；非法输入返回错误；不回显密码
- [ ] 设置成功后丢弃缓存的登录 token 并触发一次重新拉取
- [ ] 登录请求体、日志中不出现明文密码
- [ ] 1.85C 变体构建通过；最终报告写明需真机验证：改参数后重新登录、间隔变更生效、重启保留
